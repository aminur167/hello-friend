# North End Construction Ltd - Corporate Web Platform

Official web application showcasing luxury apartments, commercial landmarks, and infrastructure projects by North End Construction Ltd in Rangpur, Bangladesh.

## Highlights

- **Corporate Showcase**: Brand history, quality standards, engineering leadership, and vision.
- **Property Directory**: Filterable residential and commercial listings with detailed specifications.
- **Location Advantage**: Strategic project highlights and neighborhood accessibility.
- **Inquiry Portal**: Connected contact workflows for sales and customer support.

## Tech Stack

- **Framework**: TanStack Router, React, TypeScript
- **Styling**: Tailwind CSS, PostCSS
- **Backend Sync**: Supabase client integration
- **Deployment**: Vite, Bun runtime
